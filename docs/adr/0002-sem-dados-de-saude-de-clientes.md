# Sem dados de saúde de clientes

O sistema guarda das clientes da clínica só dados administrativos (nome, telefone e CPF) e nenhum dado de saúde. A baixa de estoque registra o lote para o controle de validade, mas o sistema não oferece rastreabilidade clínica, como a consulta de quais clientes receberam um lote num recall ou numa reação adversa. Essa consulta trataria um dado de saúde ligado a uma pessoa, sensível pela LGPD, e exigiria os controles de um prontuário, que está fora do escopo. Ela fica para quando houver prontuário.
