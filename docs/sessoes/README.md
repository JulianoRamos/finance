# Sessões

As transcrições das sessões do Claude Code que constroem o projeto, em ordem cronológica. Cada arquivo traz as mensagens, as respostas do agente, as chamadas de ferramenta com os resultados e o trabalho dos subagentes.

Elas existem para quem lê o repositório. Os agentes não as leem: a decisão vigente está sempre no documento dono dela (`AGENTS.md` da raiz, "Documentos").

O nome de cada arquivo é `<nn>-<aaaa>-<mm>-<dd>-<hhmm>-<título>.md`.
